Problem Statement & Rural Healthcare Crisis

Context & Motivation
🚨 Cardiologist Shortage & Urban Density
Over 70% of certified cardiologists in developing nations reside in Tier-1 metropolitan centers, while 65%+ of the population lives in rural villages with zero local cardiac infrastructure.
⏳ The "Golden Hour" Delay
Rural patients travel 30-80 km over poor roads for basic clinical evaluation. Delays in acute myocardial infarction or arrhythmia detection result in high mortality rates.
💸 Prohibitive Equipment Costs
Clinical 12-lead ECG machines and Holter monitors cost $3,000–$15,000, rendering village health sub-centers incapable of offering continuous telemetry.
📖 Literacy & Prescription Mismanagement
Elderly and illiterate rural patients frequently misunderstand handwritten medication regimens, risking fatal drug-drug interactions or improper anti-arrhythmic dosages.

Healthcare Use Case & Kiosk Workflow

Clinical Architecture
Step 1: Touchless Patient Arrival
Illiterate or arthritic patients activate the kiosk via speech: "Hello Doctor". Dr. Aisha greets them verbally via natural Web Speech synthesis.
Step 2: Real-Time Telemetry Pairing
The patient taps or holds a wearable smartwatch. The browser reads live heart rate over Web Bluetooth GATT and displays a 60fps dynamic EKG rhythm.
Step 3: Prescription OCR & Safety Check
Patient uploads paper prescription. Tesseract.js extracts drug names in-browser. The AI explains their effects and flags contraindications against live pulse readings.
Step 4: Emergency Escalation & Booking
If arrhythmias or critical vitals (BPM > 120 or severe angina) are detected, the system triggers SOS alerts and auto-books a verified cardiologist from doctors.json.

Technical Architecture & Stack

Engineering & Systems
💻 Frontend Architecture
• Framework: Next.js 16 (App Router) + React 19 + TypeScript
• UI / UX: Custom Glassmorphism CSS Modules, dynamic pulse animations
• Telemetry: Web Bluetooth API (GATT 0x180D) + HTML5 Canvas 60fps
• Voice: Web Speech API (Continuous ASR + TTS)
⚙️ Backend & Persistence Architecture
• API Gateway: FastAPI (Python 3.10) with Uvicorn ASGI server
• Data Layer: Flat-file JSON store (users.json, doctors.json) designed for offline-capable edge kiosks
• Security: Pydantic validation, CORS middleware, sanitized markdown output

AI/ML Model & Inference Engineering

Artificial Intelligence
🧠 Primary Tier: Qwen 27B on Colab GPU
Hosted remotely with GPU acceleration and tunneled via secure ngrok connection. Tuned with clinical triage prompts to act as Dr. Aisha, avoiding fluff and delivering concise medical assessments.
⚡ High-Availability Fallback: Groq Cloud LPU
If rural satellite internet drops or the Colab server sleeps, the gateway switches within milliseconds to Groq Cloud running LLaMA-3 / Qwen models with < 500ms TTFT (Time To First Token).
👁️ Client-Side Vision / OCR Engine
Tesseract.js compiles Google's Tesseract OCR into WebAssembly (WASM). Images never leave the kiosk unencrypted, preserving patient health data privacy under HIPAA/GDPR principles.
🛡️ Medical Guardrails & Noise Filtering
Custom regex cleans markdown symbols for clean text-to-speech voicing; prompt heuristics filter handwriting distortions and scanning noise.

Wearable Telemetry & EKG Synthesis

Biomedical IoT
📡 Web Bluetooth GATT Integration
Connects via browser to consumer wearables (Apple Watch, Polar H10, Garmin, Galaxy Watch) using the standard Bluetooth SIG Heart Rate Service (UUID 0x180D) and Measurement Characteristic (0x2A37).
📈 Dynamic Canvas Waveform Engine
Translates pulse intervals into a physiological P-Q-R-S-T cardiac waveform drawn at 60 FPS using HTML5 2D Canvas context, providing instant visual feedback to patient and remote doctor.
🔄 Integrated Telemetry Simulator
When testing in areas without physical BLE hardware or during simulated clinical trials, an internal mathematical heart rate generator mimics normal sinus rhythms, sinus tachycardia, and bradycardia.

Clinical Escalation & Doctor Network

Telemedicine Operations
🚨 Automated Emergency SOS Trigger
Abnormal biometric spikes (BPM > 120 or < 45) combined with keywords like "crushing chest pain", "left arm numbness", or "dyspnea" immediately flash red emergency warnings.
🗺️ Verified Geospatial Doctor Matching
Integrated doctors.json database maps nearest verified cardiologists with ratings, experience, latitude/longitude, and specialty for one-click tele-consultation booking.
👨‍⚕️ Doctor / Admin Management Dashboard
Dedicated administrative portal (/admin) allows hospital supervisors and local health officers to register new practicing cardiologists, monitor patient queue statuses, and review triage transcripts.
